# Course Registration System

A Full Stack Course Registration System developed using Spring Boot, HTML, CSS, JavaScript, and MySQL.

This project allows users to register for courses through a responsive frontend connected with a Spring Boot backend and MySQL database.

---

# 🚀 Features

- Student course registration
- Available course listing
- Backend API integration
- MySQL database connectivity
- Responsive frontend UI
- Success message after registration

# ⚙️ Setup Instructions

1. Clone the repository:
```bash
git clone https://github.com/jahir142/Course-Registration-System

2. Open the backend project in IntelliJ IDEA or VS Code.
3. Configure MySQL database in application.properties.
4. Create the database:
     CREATE DATABASE course_db;
5. Run the Spring Boot application.
Backend runs on:
http://localhost:8080

6. Open frontend files using browser or VS Code Live Server.
